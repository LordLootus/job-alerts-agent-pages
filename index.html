Job Alerts Agent

This is a personal, single-user automation tool that reads job-alert emails (LinkedIn and Indeed) from one Gmail account, extracts job listing details, and logs matching listings to a private Notion database. It is not a public product or service — this page exists solely to satisfy Google's OAuth consent screen requirements for the tool's own author.
