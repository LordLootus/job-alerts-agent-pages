Privacy Policy

Last updated: 12 October 2026

Autotrader Backup is a personal script built and used by one person (its author) to back up their own data. It is not distributed, offered to other users or run as a public service.

What it accesses

The tool connects to one Google Drive account through the Google Drive API, using only the drive.file scope. That scope lets it see and manage only the files it has created itself: one folder called autotrader and the nightly backup archives inside it. It cannot see, read or change any other file in the Drive.

What happens to the data

Every night it uploads an archive of the author's own trading-bot records (trade history, bot state and logs) and deletes archives older than 30 days. The data is never sold, shared with third parties or used for advertising, and it is kept nowhere except the author's own server and their own Google Drive.

Data retention and control

The tool has one user, its author, so keeping and deleting the data is entirely up to that person, through their own server and Google Drive. Access can be withdrawn at any time at myaccount.google.com/permissions.
